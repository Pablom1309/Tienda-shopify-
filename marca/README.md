# Logo Huella Sur

- `logo-horizontal.svg`: isotipo + nombre (uso principal: cabecera, documentos).
- `logo-horizontal-blanco.svg`: versión para fondos oscuros (verde de marca o fotos).
- `logo-vertical.svg`: isotipo arriba, nombre y "KITS PARA MASCOTAS · CHILE" (redes, empaque, etiquetas).
- `isotipo.svg`: solo el símbolo (favicon, foto de perfil de Instagram/Facebook/WhatsApp).
- `palabra.svg`: solo el nombre, en `currentColor` (lo usa la tienda).

Concepto: una huella dentro de un círculo y, en el cojinete, una estrella de cuatro puntas, por la Cruz del Sur (el "Sur" de Chile). El nombre va en minúsculas, en Nunito ExtraBold convertida a trazos, así que se ve igual sin tener la fuente instalada.
Colores: verde #1F5F5B, ámbar #F2A541, crema #FBF8F3.
Antes de registrar la marca, buscar en INAPI (clase 35) y nic.cl.
