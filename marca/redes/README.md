# Kit de perfil para redes

Generado desde `marca/isotipo.svg` y los íconos de la tienda (paleta "tinta y mandarina").

| Archivo | Uso |
|---|---|
| `perfil-1080.png` | Foto de perfil de Instagram, Facebook, TikTok y WhatsApp Business (1080x1080; las apps la recortan en círculo, el isotipo ya es circular). |
| `destacado-kits.png` | Portada del destacado "Kits" (1080x1920). |
| `destacado-como-comprar.png` | "Cómo comprar". |
| `destacado-envios.png` | "Envíos". |
| `destacado-cambios.png` | "Cambios". |
| `destacado-preguntas.png` | "Preguntas". |

Cómo subir una portada: abrir el destacado → Editar destacado → Editar portada → elegir la imagen desde la galería. El ícono queda al centro, así que el recorte circular no lo corta.
